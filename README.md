# Evros & Maria — Wedding Website

Wedding: **Saturday, 10 June 2028** · **Barnyard Venue, Skarinou, Cyprus**.

## Publish on GitHub Pages
Go to **Settings → Pages → Build and deployment** and select **Deploy from a branch**, branch **main**, folder **/(root)**. Save. Your public website URL will be:

https://evroscchristodoulou.github.io/evros-maria-wedding/

## Add the original logo
The site expects the approved official black E & M logo at **assets/monogram.png**. This binary image has **not** yet been uploaded to GitHub. Create the `assets` folder and upload the original logo image with that exact filename. Until then, the page displays a text E & M fallback.

## Current features
- Minimalist black and white responsive website
- Live countdown to the wedding date (Cyprus time)
- English / Greek language toggle
- Downloadable all-day Save the Date calendar file
- Installable web-app manifest and offline service worker

## Future features
Personal invitations, RSVP, guest QR codes, notifications and photo uploads require a backend; they are not active in this version.

The wedding ceremony time is not yet confirmed; the calendar event is intentionally all-day.
